### 🎯 Sobre mim

Estudante de Ciência da Computação (UFPB) em busca de estágio em **Desenvolvimento Java / Full Stack**, com foco em Backend.

Construí sozinho, do zero, aplicações completas ponta a ponta com **Spring Boot** e **React** — da modelagem do banco de dados à automação de deploy em produção — incluindo autenticação real, WebSocket, testes automatizados e CI/CD com Docker.

Aplico boas práticas de segurança por padrão (isolamento de credenciais, autorização por dono do recurso, rate limiting, proteção contra mass assignment) e mantenho o código versionado no Git com histórico limpo e organizado.

### ✨ Diferenciais

- 🚀 **Autonomia** — projeto, implemento e coloco em produção aplicações completas sem supervisão.
- 🔒 **Mentalidade de segurança** — controle de acesso e proteção de dados fazem parte do design, não são adicionados depois.
- 🧪 **Qualidade** — testes automatizados (JUnit 5, Mockito) e de integração (MockMvc) antes de considerar algo pronto.
- 💬 **Comunicação e aprendizado contínuo** — boa comunicação escrita, autodidata e fácil colaboração em equipes remotas.

### 🚀 Projetos em destaque

#### [AppStudying](https://github.com/umdevaprendiz/AppStudying) — Plataforma de Estudos com Rede Social entre Estudantes
`Spring Boot 4` · `React (Vite)` · `MySQL` · `Docker` · `WebSocket` — [em produção 🔗](https://appstudying.onrender.com)

Aplicação full-stack completa, construída e mantida sozinho: organização de estudos combinada com um componente social — parceria de estudo, feed de sugestões e chat privado em tempo real (STOMP/SockJS).

- 🔐 Verificação de e-mail obrigatória, sessão persistida em banco, autorização por dono do recurso, rate limiting e proteção contra mass assignment.
- 📦 Deploy real: Dockerfile multi-stage, CI no GitHub Actions (testes com MySQL real + build), migrations com Flyway.
- ✅ Testes unitários (JUnit 5 + Mockito) em todas as camadas de serviço e testes de integração (MockMvc).

#### [API Bank](https://github.com/umdevaprendiz/financialbank) — Sistema Bancário com Painel Financeiro
`Spring Boot` · `Spring Security` · `React (Vite) + TypeScript` · `MySQL`

API RESTful para gestão de contas e transações, com autorização por papéis (roles) via Spring Security e sessão persistida em banco (Spring Session JDBC).

- 🔍 Filtros dinâmicos com Specification (JpaSpecificationExecutor); dashboard administrativo com métricas agregadas.
- 🏗️ *Em desenvolvimento:* painel financeiro para o usuário final consumindo a API via sessão autenticada.
